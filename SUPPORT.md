# Getting help

- **Questions and how-to**: [Discussions → Q&A](https://github.com/sneakercreepers/creep/discussions/categories/q-a)
- **Ideas**: [Discussions → Ideas](https://github.com/sneakercreepers/creep/discussions/categories/ideas)
- **Bugs, false positives, false negatives**: [open an issue](https://github.com/sneakercreepers/creep/issues/new/choose)
- **Security vulnerabilities in creep**: see [SECURITY.md](SECURITY.md) — never a public issue

Before asking, run `creep doctor` and include its output (it never prints secrets).
